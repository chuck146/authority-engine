## How to read this table

- **Target URL**: an existing page wherever one fits. A new page appears only when nothing fits, and it is marked _proposed — needs owner confirmation_.
- **Section**: `FAQ` = a Q&A in the new optional `faqs` field. `New section` = a body section on the page. `Blog` = an existing or new blog post.
- **Intent**: research / cost / comparison / prep.
- **Facts needed**: what the owner must confirm before the answer can be published. Until then, the drafts use `[CONFIRM: ...]` placeholders.
